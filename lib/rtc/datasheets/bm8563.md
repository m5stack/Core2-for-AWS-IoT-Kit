# BM8563 High-Precision, Low-Power I²C Interface Real-Time Clock/Calendar

## Overview

The BM8563 is a low-power CMOS real-time clock/calendar chip that provides a programmable clock output, an interrupt output, and a power-down detector. All addressing and data transfers are performed serially via the I²C bus interface at a maximum speed of 400Kbits/s. The internal word address register automatically increments after each read/write data transfer.

### Features

- Timekeeping based on a 32.768kHz crystal: seconds, minutes, hours, weekdays, days, months, and years
- Includes century indicator
- Wide operating voltage range: 1.5V to 5.5V
- Typical standby current: 0.25μA (VDD = 3.0V, TA = 25°C)
- I²C bus slave address: Read – 0A3H; Write – 0A2H
- Programmable clock output frequencies: 32.768kHz, 1024Hz, 32Hz, 1Hz
- Alarm and timer functions
- Power-down detector
- Integrated internal oscillator capacitor
- Package types: SOP8 / MSOP8 / TSSOP8
- Open-drain interrupt output pin

### Applications

- Portable instruments
- Mobile phones
- Fax machines
- Multi-rate electricity meters, IC card water meters
- Access control, attendance machines
- Clock calendars

## Functional Description

The BM8563 has:

- Sixteen 8-bit registers
- An auto-incrementing address register
- Built-in 32.768kHz oscillator with integrated capacitor
- Frequency divider, programmable clock output
- Timer and alarm functions
- Power-down detector
- 400kHz I²C interface

Registers:

- Addresses 00H–01H: Control/status
- Addresses 02H–08H: Time counters
- Addresses 09H–0CH: Alarm settings
- Address 0DH: CLKOUT frequency
- Addresses 0EH–0FH: Timer control & value

Time and alarms use BCD encoding, while weekday is binary.

## BCD-Formatted Timekeeping Registers

| Address | Register Name   | Bit7                                           | Bit6                | Bit5                | Bit4                | Bit3 | Bit2               | Bit1 | Bit0 |
| ------- | --------------- | ---------------------------------------------- | ------------------- | ------------------- | ------------------- | ---- | ------------------ | ---- | ---- |
| 02H     | Seconds         | VL                                             | 00~59 in BCD format |
| 03H     | Minutes         | —                                              | 00~59 in BCD format |
| 04H     | Hours           | —                                              | —                   | 00~23 in BCD format |
| 05H     | Days            | —                                              | —                   | 01~31 in BCD format |
| 06H     | Weekdays        | —                                              | —                   | —                   | —                   | —    | 0~6 (binary coded) |
| 07H     | Month/Century   | C                                              | —                   | —                   | 01~12 in BCD format |
| 08H     | Year            | 00~99 in BCD format                            |
| 09H–0CH | Alarm Registers | AE flags + BCD-encoded minute/hour/day/weekday |

The **VL** bit (bit7 of the seconds register) indicates power-down detection:

- `VL=0`: no power-down
- `VL=1`: power-down has occurred

The **C** bit in month/century (07H) defines the century:

- `C=0`: 20XX
- `C=1`: 19XX

## Alarm Mode

- Alarm flags trigger interrupts by comparing timekeeping registers with programmed alarm registers when the corresponding **AE** bit is **0**.
- **AF (Alarm Flag)** is set when a match occurs. It must be cleared in software.
- Alarm occurs once per match cycle (e.g., every minute, hour, or week).

---

## Timer Configuration

- 8-bit countdown timer (register 0FH)
- Controlled via **Timer Control Register (0EH)**
- Frequencies supported: 4096Hz, 64Hz, 1Hz, or 1/60Hz
- Triggers **TF (Timer Flag)** on countdown completion
- TF can be cleared via software
- **TI/TP** controls whether INT is pulsed or level-triggered

**Table 22. Timer Clock Frequency Selection**

| TD1 | TD0 | Frequency |
| --- | --- | --------- |
| 0   | 0   | 4096 Hz   |
| 0   | 1   | 64 Hz     |
| 1   | 0   | 1 Hz      |
| 1   | 1   | 1/60 Hz   |

**Countdown Value Calculation:**

> Countdown period = `n / selected frequency` where `n` is the 8-bit value set in register 0FH.

## 🌀 Read/Write Cycles on the I²C Bus

### Read/Write Cycle Formats

There are three I²C communication modes supported:

#### Mode 1: Master Writes to Slave

**Diagram**: From master transmitter to slave receiver

```
S ──> Slave Address + Write ──> Acknowledge ──> Word Address ──> A ──> Data ──> A ──> … ──> P
```

- `S`: Start condition
- `P`: Stop condition
- `A`: Acknowledge bit
- Word address auto-increments after each byte

#### Mode 2: Random Read

**Diagram**: Write address pointer, then read

```
S ──> Slave Address + Write ──> A ──> Word Address ──> A ──>
     RESTART ──> Slave Address + Read ──> A ──> Data ──> … ──> N ──> P
```

- RESTART issued between write and read
- Master sends NACK (`N`) after last byte to indicate end of read

#### Mode 3: Sequential Read

**Diagram**: Direct read from current register pointer

```
S ──> Slave Address + Read ──> A ──> Data1 ──> A ──> … ──> Last Byte ──> N ──> P
```

> Note: In all modes, the memory address automatically increments after each byte.

## 🔄 Oscillator Selection

- The oscillator connects directly to pins **OSCI** and **OSCO**.
- For accurate operation, use a **32.768kHz crystal** with:
  - Load capacitance (**CL**) of 6pF
  - Series resistance (**ESR**) < 50kΩ
  - Optional external fine-tuning capacitors on OSCI and OSCO

### Crystal Parameters

| Parameter         | Symbol | Min | Typ    | Max  | Unit |
| ----------------- | ------ | --- | ------ | ---- | ---- |
| Frequency         | f      |     | 32.768 |      | kHz  |
| Load Capacitance  | CL     | —   | 6      | 12.5 | pF   |
| Series Resistance | ESR    | —   | 30     | 50   | kΩ   |

### Notes:

1. For crystals with 6pF load capacitance, connect ~6pF trimming capacitors to OSCI and OSCO.
2. For 12.5pF crystals, use ~19pF trimming caps instead.
3. If power supply (VCC) is noisy, consider adding decoupling resistors or capacitors for stability.
