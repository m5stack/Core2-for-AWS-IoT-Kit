# AXP192 Firmware Reference

Source: `AXP192.pdf`, X-Powers datasheet V1.2, August 8, 2011.

The checked-in source is the complete 53-page Chinese/English register
datasheet. M5Stack's current Core2 for AWS page links a shorter English
Revision 1.0 document from 2016; use the checked-in V1.2 source for the complete
register definitions represented here.

# Communication Interface

### Bus Type

Two Wire Serial Interface (TWSI / I²C compatible)

### Device Address

```
7-bit address: 0x34
8-bit write address: 0x68
8-bit read address:  0x69
```

### Clock Speed

```
Standard: 100 kHz / 400 kHz
Maximum:  1.2 MHz
```

### Electrical Levels

```
Logic low input  <= 0.3 V
Logic high input >= 2.0 V
Supply voltage for interface: 3.3 V
```

Typical wiring:

```
SDA -> pull-up 2.2k to 3.3V
SCK -> pull-up 2.2k to 3.3V
```

---

# Power Architecture

AXP192 manages power sources:

```
BAT     — Lithium battery
VBUS    — USB input
ACIN    — External adapter
```

Output system rail:

```
IPSOUT
```

Internal logic rail:

```
VINT (2.5 V internal logic power)
```

IPS automatically selects the best power source.

Priority order:

```
ACIN > VBUS > BAT
```

Behavior:

1. Battery only → system powered by battery
2. External power present → external power supplies load
3. Battery automatically supplements load if external supply insufficient
4. ACIN preferred over VBUS when both present

# Input Voltage Limits

| Parameter | Operating range | Absolute maximum range |
| --- | --- | --- |
| ACIN input voltage | 3.8V to 6.3V | -0.3V to 11V |
| VBUS input voltage | 3.8V to 6.3V | -0.3V to 11V |

The feature summary gives 2.9V to 6.3V as the overall power-management
operating range. The electrical-characteristics table requires 3.8V to 6.3V
at the ACIN and VBUS input pins. Absolute-maximum values are stress limits, not
normal operating targets.

Operating temperature: -40°C to 130°C.

## Charging Phases

### 1. Pre-charge

Condition:

```
Battery voltage < 3.0 V
```

Current:

```
10% of configured charge current
```

Timeout:

```
40 minutes
```

---

### 2. Constant Current

Active when:

```
VBAT > 3.0 V
```

Current:

```
Configured current
```

IRQ generated if external supply cannot support configured current.

---

### 3. Constant Voltage

When battery reaches:

```
VTRGT (target charge voltage)
```

Charge current gradually decreases.

---

### Charge Termination

Occurs when:

```
Charge current < 10% or 15% of configured current
```

IRQ18 generated.

---

### Recharge

Restart when:

```
VBAT < VTRGT − 0.1V
```

# AXP192 Complete Register Map (Driver Reference)

This document defines the **AXP192 register interface** used through the **TWSI/I²C host interface**.

Device address:

```
0x68
```

Registers are **8-bit wide**.

Bit numbering:

```
7 = MSB
0 = LSB
```

---

# Register Groups

Registers fall into functional groups:

```
0x00–0x0F  Power status / input detection
0x10–0x1F  Output enable & voltage control
0x20–0x2F  DC-DC voltage configuration
0x30–0x3F  Power path / charging / thresholds
0x40–0x4F  Interrupt enable & status
0x50–0x6F  ADC data
0x70–0x7F  Power / battery / APS ADC data
0x80–0x8F  ADC & DC-DC mode configuration
0x90–0x9F  GPIO / PWM configuration
0xB0–0xB8  Coulomb counter / fuel gauge
```

# 0x28 — LDO2 / LDO3 Voltage

A single register holds both LDO2 and LDO3 voltages.
Reset value: `0xCF`

| Bits | Field        | Formula                            |
| ---- | ------------ | ---------------------------------- |
| 7-4  | LDO2 voltage | `Voltage = 1.8V + (field * 0.1V)`  |
| 3-0  | LDO3 voltage | `Voltage = 1.8V + (field * 0.1V)`  |

Both fields cover 1.8V – 3.3V in 100 mV steps. LDOIO0 voltage (GPIO0 in
LDO mode) is set separately in REG91H[7:4]; LDO1 is fixed/always-on.

# 0x31 — VOFF Shutdown Voltage Setting

Address

```
0x31
```

Reset value: `0bXXXX_X011` (VOFF bits = 011)

Fields

| Bits | Function                                                          |
| ---- | ----------------------------------------------------------------- |
| 7-4  | reserved                                                          |
| 3    | Sleep-mode PWRON short-press wake enable (self-clears after set)  |
| 2-0  | VOFF shutdown voltage                                             |

VOFF voltage (bits 2-0)

```
000 = 2.6V   001 = 2.7V   010 = 2.8V   011 = 2.9V
100 = 3.0V   101 = 3.1V   110 = 3.2V   111 = 3.3V
```

When APS falls below VOFF, AXP192 shuts down all outputs except LDO1.
Warning thresholds (VWARNING Level1/Level2) are set in REG3AH/REG3BH.

## REG38H / 39H / 3CH / 3DH — NTC threshold registers

8-bit thresholds for charge (38/39) and discharge (3C/3D) battery
temperature, with `V_threshold = REG * 0x10 * 0.0008V` (0–3.264V).

```c
#define AXP192_REG_VLTF_CHARGE    0x38  /* reset A5 -> 2.112V */
#define AXP192_REG_VHTF_CHARGE    0x39  /* reset 1F -> 0.397V */
#define AXP192_REG_VLTF_DISCHARGE 0x3C  /* reset FC -> 3.226V */
#define AXP192_REG_VHTF_DISCHARGE 0x3D  /* reset 16 -> 0.282V */
```

## REG84H — ADC sample rate / TS pin control

`REG84H[7:6]` ADC sample rate (`25 * 2^n` Hz), `REG84H[5:4]` TS bias
current, `REG84H[2]` TS mode. Reset value `0x32`.

```c
#define AXP192_ADC_RATE_MASK               (0x3u << 6) /* REG84H[7:6] */
#define AXP192_TS_CURRENT_MASK             (0x3u << 4) /* REG84H[5:4] */
#define AXP192_TS_MODE_EXTERNAL_ADC        (1u << 2)   /* REG84H[2] */

typedef enum {
    AXP192_ADC_RATE_25HZ  = 0,
    AXP192_ADC_RATE_50HZ  = 1,
    AXP192_ADC_RATE_100HZ = 2,
    AXP192_ADC_RATE_200HZ = 3
} axp192_adc_rate_t;

typedef enum {
    AXP192_TS_CUR_20UA = 0,
    AXP192_TS_CUR_40UA = 1,
    AXP192_TS_CUR_60UA = 2,
    AXP192_TS_CUR_80UA = 3
} axp192_ts_current_t;
```

## GPIO mode fields

Per the register section (authoritative): `REG90H[2:0]` = GPIO0 mode,
`REG92H[2:0]` = GPIO1 mode, `REG93H[2:0]` = GPIO2 mode, `REG95H[3:2]` =
GPIO4, `REG95H[1:0]` = GPIO3, with `REG95H[7]` selecting GPIO[4:3] as GPIO
function. (The pin-description table swaps the REG92/REG93 labels; the
register definitions above are correct.)

```c
#define AXP192_GPIO0_MODE_MASK             0x07u  /* REG90H[2:0] */
#define AXP192_GPIO1_MODE_MASK             0x07u  /* REG92H[2:0] */
#define AXP192_GPIO2_MODE_MASK             0x07u  /* REG93H[2:0] */
#define AXP192_GPIO43_AS_GPIO              (1u << 7) /* REG95H[7] */
#define AXP192_GPIO4_FUNC_MASK             (0x3u << 2) /* REG95H[3:2] */
#define AXP192_GPIO3_FUNC_MASK             (0x3u << 0) /* REG95H[1:0] */

/* GPIO0 (REG90H[2:0]) mode encoding */
typedef enum {
    AXP192_GPIO0_NMOS_OD    = 0, /* 000 NMOS open-drain output */
    AXP192_GPIO0_INPUT      = 1, /* 001 general input */
    AXP192_GPIO0_LDO        = 2, /* 010 low-noise LDO (LDOIO0) */
    AXP192_GPIO0_ADC        = 4, /* 100 ADC input */
    AXP192_GPIO0_OUTPUT_LOW = 5, /* 101 output low */
    AXP192_GPIO0_FLOATING   = 6  /* 11X floating */
} axp192_gpio0_mode_t;
/* GPIO1/GPIO2 use the same encoding except code 010 = PWM1/PWM2 output. */
```

## Useful data-field masks

For driver helpers, these are safe because they follow directly from the documented bit ranges:

```c
#define AXP192_BITS_7                      (1u << 7)
#define AXP192_BITS_6_5                    (0x3u << 5)
#define AXP192_BITS_5_3                    (0x7u << 3)
#define AXP192_BITS_3_0                    (0xFu << 0)
#define AXP192_BITS_2_0                    (0x7u << 0)
#define AXP192_BITS_1_0                    (0x3u << 0)
```

## Minimal helper macros

```c
#define AXP192_FIELD_GET(v, mask, shift)   (((v) & (mask)) >> (shift))
#define AXP192_FIELD_PREP(mask, shift, v)  (((v) << (shift)) & (mask))
```
