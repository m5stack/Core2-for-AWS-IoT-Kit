# SY7088 Boost Regulator Technical Reference

Source: `SY7088.pdf`, Silergy application note AN_SY7088 Revision 0.1A.

## Device Overview

The **SY7088** is a synchronous boost DC-DC regulator designed to increase a low input voltage to a higher regulated output voltage.

The regulator uses:

* **NMOS main switching transistor**
* **PMOS synchronous rectifier**

It provides:

* Adjustable output voltage
* Output disconnect during shutdown
* Under-voltage lockout
* Over-voltage protection
* Thermal shutdown
* Soft-start
* Peak current limiting

The switching frequency is approximately **1 MHz pseudo-constant frequency**.

# Pin Functional Description

## LX (Pins 1, 2)

Switch node connected to the inductor.

Connection:

```
Inductor between IN and LX
```

This node carries high switching currents.

---

## EN (Pin 3)

Enable input controlling regulator operation.

Internal behavior:

```
Internal pull-down resistor = 1 MΩ
```

Logic thresholds:

| State       | Voltage |
| ----------- | ------- |
| Enable High | >1.2 V  |
| Enable Low  | <0.4 V  |

Behavior:

| EN State | Device State       |
| -------- | ------------------ |
| High     | Regulator enabled  |
| Low      | Regulator disabled |

Shutdown current is reduced to **<1 µA** when disabled. 

---

## SGND (Pin 4)

Signal ground reference.

Used for:

* Feedback divider
* control circuitry

Should connect to ground plane.

---

## FB (Pin 5)

Feedback input used to regulate output voltage.

The device maintains:

```
FB = VREF
```

### Reference Voltage

```
VREF ≈ 1.2 V
```

Measured typical:

```
1.182 V – 1.218 V
```

Output voltage is set using a resistor divider.

---

## IN (Pin 6)

Input supply voltage.

Recommended decoupling:

```
≥1 µF ceramic capacitor to ground
```

The capacitor should be placed close to the pin.

---

## OUT (Pins 7, 8)

Power output node.

Recommended output capacitor:

```
≥10 µF ceramic capacitor
```

Used as output of boost converter.

---

## PGND (Pin 9, Exposed Pad)

Power ground for switching currents.

Must be connected to ground plane for:

* thermal performance
* current return path

# External Components

The regulator requires four main external components:

| Component                 | Purpose                             |
| ------------------------- | ----------------------------------- |
| Inductor (L)              | Energy storage for boost conversion |
| Input capacitor (CIN)     | Stabilizes input supply             |
| Output capacitor (COUT)   | Stabilizes output voltage           |
| Resistor divider (RH, RL) | Sets output voltage                 |

These components are shown in the typical application diagram on **page 1**. 

---

# Output Voltage Programming

Output voltage is determined by the feedback divider:

```
VOUT = VREF × (1 + RH / RL)
```

Where:

```
VREF ≈ 1.2 V
```

Recommended resistor values:

```
10 kΩ – 1 MΩ
```

Higher values reduce quiescent current.

---

# Inductor Selection

Inductance is chosen based on desired ripple current.

Recommended ripple current:

```
≈ 40% of maximum output current
```

Inductance calculation:

```
L = (VIN / VOUT)² × (VOUT − VIN) / (FSW × IOUT_MAX × 0.4)
```

Where:

| Parameter | Meaning                |
| --------- | ---------------------- |
| VIN       | input voltage          |
| VOUT      | output voltage         |
| FSW       | switching frequency    |
| IOUT_MAX  | maximum output current |

---

## Inductor Current Rating

Minimum saturation current must exceed peak inductor current:

```
ISAT > IOUT_MAX × (VOUT / VIN) + ripple_current / 2
```

Recommended:

```
DCR < 50 mΩ
```

to maximize efficiency.

---

# Input Capacitor Selection

Input capacitor reduces supply ripple.

Recommended capacitor:

```
22 µF ceramic
X5R dielectric or better
```

Placement requirement:

```
as close as possible to IN and GND pins
```

---

# Output Capacitor Selection

The output capacitor stabilizes voltage and minimizes ripple.

Recommended:

```
≥22 µF ceramic
≥10 V rating
X5R dielectric or better
```

---

# Enable Control Behavior

The regulator can be controlled by a microcontroller using the **EN pin**.

### Enable thresholds

| Condition            | Voltage |
| -------------------- | ------- |
| EN rising threshold  | 1.2 V   |
| EN falling threshold | 0.4 V   |

---

## Shutdown Mode

When:

```
EN < 0.4 V
```

Behavior:

* Converter stops switching
* Output disconnects from input
* Shutdown current:

```
< 1 µA
```

---

## Startup Behavior

Soft-start time:

```
≈ 0.5 ms
```

This prevents large inrush current during startup.

During startup the output is pre-charged with a linear charge current
(measured at startup conditions):

| Condition                  | Linear charge current |
| -------------------------- | --------------------- |
| VOUT < 1 V                 | 1.2 A                 |
| 1 V ≤ VOUT < (VIN − 0.2 V) | 1.0 A                 |

---

# Protection Features

## Input Under Voltage Lockout (UVLO)

```
Threshold ≈ 2.3 V
Hysteresis ≈ 0.1 V
```

Below this voltage the converter shuts down.

---

## Over Voltage Protection (OVP)

```
Trigger ≈ 6 V on OUT pin
Hysteresis ≈ 0.2 V
```

Protects load from excessive output voltage.

---

## Current Limit

Peak switch current limit:

```
≈ 3 A
```

Protects inductor and internal switches.

---

## Thermal Shutdown

Shutdown temperature:

```
150 °C
```

Hysteresis:

```
20 °C
```

The device restarts automatically after cooling.

# Layout Guidelines

Critical layout practices:

### Grounding

* Maximize copper area connected to ground
* Connect **PGND and SGND directly to exposed pad**

### Input capacitor placement

Must be placed:

```
directly between IN and GND pins
```

---

### Output loop

The loop formed by:

```
COUT
OUT
PGND
```

must be minimized to reduce ripple.

---

### LX node

Copper area connected to LX must be minimized to reduce noise.

---

### Feedback routing

The following must **not run near LX**:

```
FB trace
RH
RL
```

to prevent switching noise injection.

---

# Typical Component Placement

Components that should be placed close to the IC:

```
Input capacitor
Output capacitor
Inductor
Feedback resistors
```

This reduces noise and improves efficiency.

# Summary of MCU Interaction

Although the SY7088 has no digital interface, an MCU can interact through the **EN pin**.

Control capabilities:

| Control           | Method            |
| ----------------- | ----------------- |
| Enable converter  | Drive EN high     |
| Disable converter | Drive EN low      |
| Power sequencing  | Control EN timing |

The MCU cannot configure internal parameters; voltage regulation is determined entirely by external resistor divider values.
